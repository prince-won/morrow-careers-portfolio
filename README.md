# Morrow Careers

Morrow Careers is an interactive recruiting case study designed to explore how a recruiting process can be structured from both the candidate and recruiter perspectives.

The project covers:

- Job Definition
- Candidate Experience
- Applicant Pipeline
- Structured Evaluation
- Recruiting Analytics
- Process Improvement

Morrow is a fictional company and all recruiting data presented in this project is fictional.

## Sprint 01

Sprint 01 establishes the shared product foundation:

- React + TypeScript + Vite project setup
- Candidate and Recruiter route layouts
- Shared navigation and view switching
- Responsive design tokens and base UI primitives

Later screens are intentionally represented by foundation placeholders until their defined sprint begins.

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build`.
